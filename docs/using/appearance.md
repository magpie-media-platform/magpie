# Appearance

[Documentation](../README.md) / [Everyday use](README.md)

Each browser can have its own theme. This does not change the [instance defaults](../administration/configuration.md#theme-defaults).

## Selecting a theme

Open the account menu and select **Theme**. The **Mode** decides which theme the browser uses.

| Mode | Result |
| --- | --- |
| Default | Uses the instance mode and themes. |
| Dark | Uses the selected dark theme. |
| Light | Uses the selected light theme. |
| System | Follows the device, switching between the selected light and dark themes. |

Outside **Default**, you also pick a **Light theme** and a **Dark theme**. Changes apply immediately.

## If a theme is unavailable

[Extensions](../administration/extensions.md) can add themes. If the selected theme is unavailable, Magpie uses the built-in Tokyo Night dark theme. Select another theme or **Default**. If the instance theme is also unavailable, an administrator must [replace the instance defaults](../administration/configuration.md#theme-defaults).
