# Magpie SDK

[Magpie](https://github.com/magpie-media-platform/magpie) is a self-hosted media manager for any media type, including movies, TV shows, music, and books, with the ability to add more through extensions.

This is the SDK for building Magpie extensions. The [extension development guide](https://github.com/magpie-media-platform/magpie/blob/main/docs/development/extensions.md) on GitHub covers how to use it.
